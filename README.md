# Cosmora TV

Aplicación Android + Android TV de televisión en vivo desarrollada por **Ozzylator Labs**.

## Objetivos
- Interfaz oscura/cósmica optimizada para celular y televisor.
- Navegación táctil y con control remoto (D-pad, OK, Atrás, Play/Pausa y Channel +/-).
- Reproducción HLS mediante AndroidX Media3 / ExoPlayer.
- Catálogo curado: sin listas IPTV piratas ni proxies de canales de pago.
- TVN y Canal 13 integrados inicialmente mediante sus páginas oficiales mientras se documenta una señal directa apta para terceros.
- Salidas APK y AAB mediante GitHub Actions.

## Identidad
- Nombre: **Cosmora TV**
- Package: `cl.ozzylatorlabs.cosmoratv`
- Versión inicial: `1.0`
